# KESI Android 2.0

한국 경제 스트레스를 공식 통계 원자료로 모니터링하는 Android 앱 및 홈 화면 위젯.
검증 기준: 2026-11-10. KESI 점수는 사용자 정의 휴리스틱이며 공식 기관의 지수 또는 위기 발생확률이 아니다.

## 구현
- Android 8.0(API 26) 이상, target/compile API 35, Java 17, AGP 8.7.3 / Gradle 8.9.
- 홈 화면 위젯, 앱 내 위젯 추가, 수동 새로고침, 네트워크 연결 시 6시간 주기 JobScheduler 갱신.
- 한국은행 ECOS 공식 HTTPS API에서 5개 지표 자동수집. PF는 검증된 자동수집 경로가 없어 미수집.
- ECOS 공개 접근 문자열 `sample`은 API 인증키 자리의 공개 제한 모드이며 앱에 내장된 샘플 수치가 아니다. 요청당 10행 한도를 지키며 실제 요청기간/코드/단위/중복을 검증한다. API 제공 정책 변경 또는 오류 시 미수집으로 처리한다.
- 원자료, 개별 0~100점, 관측 기준기간, 수집시각(KST), 발표일 필드, 공식 원자료 링크.
- ECOS StatisticSearch는 발표일을 제공하지 않으므로 **발표일 미확인**으로 표시한다. 수집일/기준기간을 발표일로 위장하지 않는다.
- 종합 0~100점·위험등급은 6개 모두 유효할 때만 계산. 하나라도 미수집이면 종합 산출을 보류한다. 따라서 현재 PF 미수집 상태에서는 종합 점수와 위험등급이 나오지 않는 것이 정상 동작이다.
- 이전 v1 샘플 및 캐시와 분리된 schema 2 저장소. 초기 설치와 파싱 실패 시 숫자 대체값 없음.
- 통신 실패 시 이전 관측값을 ‘수집 실패·이전 자료’로 표시하고 종합 산출에서 제외.

## 통계 정의와 출처

| 지표 | 공식 계열 | 변환 |
|---|---|---|
| 은행 기업대출 연체율 | ECOS 901Y124 / MO3AA / AB / M, 은행연합회 | 은행전체 **기업대출**, 1개월 이상 연체율. 국내은행 전체 원화대출 총연체율과 다름 |
| 실업률 | ECOS 901Y027 / I61BC / I28B / M, 국가데이터처 | 계절조정 실업률 |
| 주택가격 | ECOS 901Y149 / 00 / a0 / M, 한국부동산원 | 전국 종합 매매가격지수(2026.06=100)의 전년비. 동일 기준년 자료끼리만 계산 |
| 회사채 신용 | ECOS 817Y002 / 010300000 및 010200000 / D | 같은 날짜 회사채 AA− 3년 금리 − 국고채 3년 금리, %p |
| 원/달러 | ECOS 731Y001 / 0000001 / D | 매매기준율, 원/USD. 장중가 또는 종가가 아님 |
| PF | 금융위원회·금융감독원 금융권 PF대출 연체율 | 미수집. 뉴스 수치/수동 입력/과거 고정값으로 대체하지 않음 |

원자료 제공: https://ecos.bok.or.kr/api/ , https://ecos.bok.or.kr/
한국부동산원 API 안내: https://www.reb.or.kr/r-one/portal/openapi/openApiIntroPage.do
PF 공식 발표기관: https://www.fsc.go.kr/ (이번 구현에서 안정적 자동 파싱을 검증하지 못함)

출처 수준: 공식 기관 API 및 기관 통계표. 수치 최신성은 각 응답의 기준기간으로 판단한다.

## 점수 규칙 v2
원 프로젝트에 있던 가중치·시스템 스트레스 가산점·등급 경계를 유지했다.
원 프로젝트는 이미 만들어진 샘플 점수만 있었으므로, 아래 원자료→점수 변환 기준은 이번 버전에서 명시적으로 추가한 **임의의 고정 구간**이다. 백테스트/통계적 보정을 마친 기준이 아니다.

| 지표 | 가중치 | 0점 원자료 | 100점 원자료 |
|---|---:|---:|---:|
| 은행 기업대출 연체율 | 25% | 0.2% | 2% |
| 계절조정 실업률 | 15% | 2% | 6% |
| 전국 주택가격 전년비 하락폭 | 15% | 0% | 10% 하락 |
| 회사채 스프레드 | 20% | 0.3%p | 3%p |
| 원/달러 | 10% | 1,100원 | 1,600원 |
| PF 연체율 | 15% | 1% | 10% |

구간 내 선형 변환, 구간 밖은 0~100에 제한. 70점 이상 지표가 2/3/4개 이상이면 +3/+6/+10점. 최종 최대 100점.
등급: 정상 <30, 주의 <45, 경계 <60, 위기 전조 <75, 위기 ≥75.
이 규칙은 환율의 장기 추세 변화, 주택가격 급등 위험 등을 모두 반영하지 못한다.

### 3개월 변화
각 지표의 최신 관측기간에서 정확히 3개월 전으로 이동한다. 일별은 해당 비교일 이전 7일 이내 최근 영업일을 사용한다. 회사채와 국고채는 두 시점 모두 날짜를 맞춘다.
월별은 정확한 3개월 전 월이 없으면 비교 불가. 주택가격은 전년비 변화이므로 전년비의 차이를 %p로 표시한다. 종합 변화는 6개 현재/과거 점수가 모두 있을 때만 산출한다.
이 값은 현재 조회되는 수정 통계의 관측기간 비교이며, ‘3개월 전에 실제로 공표되어 있던 자료로 만든 당시 지수’가 아니다. 발표 지연과 빈도가 서로 다른 자료를 섞은 실시간 백테스트로 사용하면 안 된다.

### 결측 및 유효기간
일별 10일, 월별 120일, PF 200일보다 오래된 관측기간은 종합 산출 제외. 월별 기준기간의 말일로 경과일을 센다. 미래 기준기간/응답의 잘못된 항목/중복 관측은 거부한다. 기준년 변경 시 주택가격을 다른 기준년과 섞지 않고 실패 처리한다.

## 빌드 및 설치
```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```
Android SDK 플랫폼 35, Build Tools 34.0.0 필요. GitHub `.github/workflows/build.yml`은 main push, PR, 수동실행을 지원하며 테스트·lint·APK 서명 확인 후 APK와 검증 보고서를 Artifacts에 올린다.
앱이 직접 공식 API에 접근하므로 API 키/별도 서버/개인정보 입력이 필요 없다.

APK는 개인 설치용 debug 서명이다. Play Store 배포용 정식 릴리스 서명은 별도다. 다른 빌드 환경의 debug 서명과는 일치하지 않을 수 있어 기존 설치 제거가 필요할 수 있다.
APK 설치 후 앱을 한 번 열고 새로고침한 다음 ‘홈 화면에 위젯 추가’를 누르거나, 홈 화면을 길게 눌러 위젯 → KESI를 선택한다.
자동 갱신은 절전/네트워크/강제종료에 영향을 받는다. 강제종료 후에는 앱을 다시 열어야 한다.
