# KESI 4.0 데이터 및 검증 계약

AI-A는 한국의 시스템적 은행위기 시작을 예측 대상으로 삼는다. 사건 정의와
라벨의 출발점은 IMF Laeven·Valencia *Systemic Banking Crises Database:
1970–2025* (2026, DOI 10.5089/9798229045971.001)이다. 연 단위로만
확인되는 시작일은 월 단위로 임의 배정하지 않는다. 감독기관의 사건 자료로
정확한 시작월을 입증하기 전에는 해당 기간을 학습·평가에서 제외한다.
한국 단독 사건 수가 충분한지 별도로 확인한다. KESI 점수는 정답으로 사용하지 않는다.

AI-B의 두 사건은 예측 기준 거래일 종가 대비 이후 5·20·60 실제 거래일의
최저 종가 하락률이 각각 10%·20% 이상인 경우다.
완전히 관측되지 않은 미래 창은 결측이다. 누락 거래일을 휴장일로
간주하지 않는다. 공식 KRX 거래일 캘린더와 대조한 뒤 라벨을 만든다.

학습용 CSV는 날짜별로 그때 이미 공개된 데이터만 담는다. 원천별 공개일,
기준일, 당시 공개값의 출처를 별도 원장에 보존한다. 현재 수정계열을
과거로 소급하거나 과거 시점을 맞추려고 공개일을 추정하지 않는다.
이 브랜치의 엔진은 연구용으로만 실행되며 모델을 자동 배포하지 않는다.

KRX 요청에는 서버 환경변수 `KRX_AUTH_KEY`가 필요하다. 저장소 및 APK에
키를 기록하지 않는다. 실제 금융위기 라벨·과거 시점별 특성·충분한
독립 사건 수가 확보될 때까지 앱은 두 예측을 검증 대기로 표시한다.

기존 정기 통계 수집은 운영 브랜치에서 계속된다. 작업 브랜치의 수집
변경은 운영에 배포하기 전까지 앱의 원격 데이터를 바꾸지 않는다.

서버에서 연구를 재실행할 때 `backend/kospi_history.py`의 월별 체크포인트로
공식 데이터 수집을 재개할 수 있다. `ai/audit_market.py`는 만기 도달 표본과
중첩 급락 묶음을 집계하고, `ai/market_backtest.py`는 학습 라벨 종료일을
검사한 뒤 별도 확률 보정과 시계열 평가를 수행한다. 연구 결과를 운영 피드에
자동 게시하지 않는다. 운영 피드의 선택적 `marketForecasts`에 검증된
항목이 없거나 오래됐으면 앱은 해당 항목만 검증 대기로 표시한다.
